## Our preparation checklist (recommendations)

- Push the reviewed source to the public Rebound repository and verify judge access.
- Check that .env, API credentials, database files and logs are excluded.
- Explain python start.py, prerequisites, fallback mode and the two demo scenarios.
- Include architecture, measured recovery evidence, known limits and honest provider status.
- Validate setup from a fresh checkout on another machine.
- Keep a short demo recording as a backup; the public page does not list it as mandatory.
- If adding a hosted demo, verify access control and keep recovery infrastructure private.
- Review all links and PDF before the leader's final confirmation.
